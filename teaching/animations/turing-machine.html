Turing machines  ·  configurations, nondeterminism and the tableau

A Turing machine is a finite control with a read/write head on an unbounded tape — and a configuration C = α q β is nothing but a word: tape content αβ, current state q, head on the first symbol of β. The page runs a machine step by step and shows, side by side, the tape picture, the configuration string, and the case of the computation relation ⊢ that produced it, while counting time and space. For a nondeterministic machine the computation is a tree: pick branches by clicking, or let the page find an accepting computation — the sequence of choices is the certificate.

One transition per line, q a -> q' b D with D ∈ {L, R, N} (read a in state q: write b, move D, go to q'). The blank □ is written _. Several lines for the same (q, a) make the machine nondeterministic; a missing line makes δ(q,a) = ∅, a dead end.

Directives: start (default: state of the first transition), halt (default qhalt), input (the word to run on), sigma (input alphabet, default: all non-blank symbols read from the input), name, limit (time limit), note (a remark shown at the start of the run). Lines starting with # are comments.

Conventions, as in the lecture. A configuration α q β ∈ Γ*QΓ+ is identified with all versions that differ in leading □s of α or trailing □s of β; the page always shows the shortest representative (keeping β ≠ ε). At the boundary (n = 1 moving right, m = 0 moving left) the rule of ⊢ is applied to αqβ□ resp. □αqβ. M(x) = {y : q0x ⊢* qhalty}: the machine produces output only if it halts with nothing left of the head; then y = β ∈ Γ+. M accepts x iff 1 ∈ M(x). timeM(x) = sup{t : q0x ⊢t qhalty} ∪ {0}, spaceM(x) = sup{|αβ| : q0x ⊢* αqβ} ∪ {0}. The Corner cases examples in the machine menu exercise each of these rules.
