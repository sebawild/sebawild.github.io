Left-leaning red-black BSTs  ·  2-3 trees in disguise

A left-leaning red-black BST represents a 2-3 tree: a red link glues a node to its parent, and the two together form one 3-node; the black links are the links of the 2-3 tree. So red links lean left, no node has two red links, and every path from the root to a null link sees the same number of black links. In the 2-3 view, red links are drawn horizontally and each 3-node as one shaded blob; the red-black BST view shows the binary tree itself. put inserts at the bottom with a red link and repairs right-leaning and double red links on the way back up; delete pushes a red link down along the search path (moveRedLeft / moveRedRight), so that the key is finally removed from a 3-node, and re-balances on the way up.

Input
Keys are put in the order given, as in Sedgewick & Wayne’s tinyST.txt (S E A R C H E X A M P L E); putting a key that is already there only replaces its value, so the tree stays the same. A line init: … builds a starting tree without animation. Operations, one per line or inline: put K (or just K), delete K, deleteMin, deleteMax. Keys: words of up to 5 characters (letters are turned into capitals) or numbers, not mixed; # starts a comment.
