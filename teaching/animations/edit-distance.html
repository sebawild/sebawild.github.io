Edit distance  ·  the DP table, step by step

How many single-character insertions, deletions and substitutions does it take to turn A into B? Guess what happens at the last positions, and the answer follows from three smaller subproblems. The table below is D(i,j) = dedit(A[0..i), B[0..j)); every cell is the minimum over three incoming arrows. The table gives only the cost — the backtrace at the end recovers an actual edit script. Hover a cell to see its prefixes; click a cell to align exactly those prefixes.

Input
Two non-empty lines: the first is A, the second is B. Lines starting with # are ignored, so a file can carry several examples with comments. Spaces inside a line are kept and drawn as ␣, which makes word-level examples (the quick fox) work as well as character-level ones.

Anything longer than 40 characters is refused: the table would be unreadable and the point of the picture is lost. For the asymptotics that is irrelevant anyway — the algorithm is Θ(mn) whatever the strings look like.
