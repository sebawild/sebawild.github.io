About this page — conventions and what to look for

Input. Type the text and the pattern directly; spaces are allowed and are drawn as ␣. Every input is encoded in the page URL, so Copy link gives a link that reopens exactly this example.

The picture. One row per guess i. The shaded cells are where the pattern currently sits; a letter appears in a cell as soon as that position has actually been compared, and the character that caused the mismatch is red. So the letters you see are exactly the work the algorithm did.

Cost. Each execution of the test T[i+j] ≠ P[j] counts as one character comparison. The chip n · m is the trivial upper bound: for text abbbababbab and pattern abba the bound is 44 and the algorithm needs 15. Try aaaaaaaaaaa with aaab to see the worst case (n−m+1)·m, where almost every check is wasted.
