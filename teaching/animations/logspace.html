Connectivity with a logarithmic memory

Is there a path from s to t? With linear memory, BFS answers this for any graph. Here the work tape holds only O(log n) bits — a handful of vertex names and counters. Three ways to cope: Reingold (deterministic, undirected), guessing (nondeterministic, directed), and Savitch (deterministic, directed, at the price of log² n). Where the problems liveclick a problem
Solid borders: classes; known strict separation: NL ⊊ PSPACE (space hierarchy, via NL ⊆ L² ⊊ PSPACE). Whether L ≠ NL, NL ≠ P, or P ⊆ L² is open. RL sits between L and NL (dashed, it might equal either).
Configuration graph of a log-space machinewhy STCON is the problem
A configuration is a snapshot (state, input-head position, work-head position, work-tape contents). With s(n) work cells there are at most |Q| · (n+2) · s · |Γ|s of them — for s = c log n that is a polynomial. Draw an edge c → c′ whenever the machine can move from c to c′ in one step. Then M accepts x exactly if an accepting configuration is reachable from the start configuration. Three consequences: (i) NL ⊆ P by BFS on this graph; (ii) every NL problem reduces to STCON, because a log-space transducer can print the graph; (iii) Savitch's recursion runs on this graph without writing it down — the test “c ⊢ c′?” needs only O(s) space — giving NSPACE(s) ⊆ DSPACE(s²) for s ≥ log n.
The machine model
Read-only input of length n (free), a work tape of O(log n) cells (that is all that is counted), and for reductions a write-only, left-to-right output tape (also free). Logarithmic space buys a constant number of pointers into the input, or counters up to a polynomial. Log-space reductions compose (recompute output bits on demand instead of storing them), so “≤L” is transitive and L, NL are closed under it.

Open, and worth knowing for research

Is L = NL? Equivalently: is STCON in L? Is STCON in DSPACE(o(log² n))? Reingold explicitly suggested re-evaluating the belief that Savitch is optimal.

Is RL = L? Saks–Zhou give RL ⊆ L3/2; Nisan gives RL ⊆ SC (polynomial time and polylog space simultaneously). Whether STCON ∈ SC is open.

Unambiguity: NL ⊆ UL/poly (Reinhardt–Allender 2000); planar directed reachability is in UL ∩ coUL (Bourke–Tewari–Vinodchandran 2009).

The idea in one sentence: first improve the graph's connectivity, then search it. On a constant-degree expander, every vertex is within O(log n) steps of every other in its component, so trying all short walks takes only O(log n) bits (①). Reingold turns every component into an expander by repeated powering (better connectivity, larger degree) and zig-zag products (degree back down) (②) — and evaluates the resulting huge graph's neighbour function in place, with constant extra memory per level (③, ④). The randomized algorithm that all this derandomizes — a plain random walk — is ⑤.

The numbers for this n
Step 0: make it regular and non-bipartite
Reingold's simple (not size-optimal) preprocessing: each vertex v becomes a cycle (v,1), …, (v,N) (labels 1, 2); label 3 at (v,w) goes to (w,v) if vw is an edge and is a self-loop otherwise; all labels > 3 are self-loops. Components are preserved, the self-loops kill bipartiteness, and the degree is the constant D16.
Why only undirected?
Everything rests on the walk matrix being symmetric: then a connected, non-bipartite graph has an inverse-polynomial spectral gap, powering raises λ to a power, and the zig-zag theorem controls the product. For directed graphs a random walk from s can need exponential time to hit t, there is no spectral gap to amplify, and no analogue of the transformation is known — STCON stays at Savitch's log² n.

Pseudocode (Aleliunas, Karp, Lipton, Lovász, Rackoff 1979)
Undirected, connected: H(s,t) ≤ H(s,t) + H(t,s) = 2m·R_eff(s,t) ≤ 2m·dist(s,t) ≤ 2m(n−1) (commute time = 2m × effective resistance). By Markov's inequality the walk misses t within T = 4m(n−1) steps with probability ≤ ½; it never accepts wrongly. Here m counts parallel edges with multiplicity.
What Reingold derandomizes
Replacing the coin flips by all possible flip sequences is exactly ① — but a random walk needs polynomially many steps, so there are 2poly(n) sequences. Only on an expander, where O(log n) steps suffice, does the enumeration fit in O(log n) bits; ②–④ build that expander. Switch to directed on the reset-path preset to see why none of this helps for STCON.

More NL-complete problems, in brief

Distance. “dist(s,t) ≤ k?” (guess a path, count to k; hard by taking k = n−1). “dist(s,t) = k?” and “> k?” are in NL only thanks to NL = coNL.

Acyclicity. “Is G a DAG?” is the complement of cycle detection, hence NL-complete as well (NL = coNL).

Automata. DFA emptiness, DFA universality and DFA equivalence (emptiness of the symmetric difference via the product automaton, which a log-space machine can simulate on the fly); NFA emptiness and the NFA word problem. Contrast: NFA universality and NFA equivalence are PSPACE-complete.

Logic. 2-SAT and 2-UNSAT (shown above). Contrast: Horn-SAT is P-complete, 3-SAT NP-complete.

What drops into L instead. Undirected s-t connectivity (Reingold; L-complete under first-order reductions), and everything that reduces to it: is an undirected graph bipartite, a forest, connected; reachability when every vertex has out-degree ≤ 1 (follow the unique pointer n steps). The step from “out-degree 1” to “out-degree 2” is exactly where nondeterminism enters.
